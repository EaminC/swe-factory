Chat Output has an error when used with an LLM with streaming enabled
### Bug Description

Since I fast-forwarded my repo to the latest upstream, I often get this:

An error occured in the Chat Output Component, stopping your flow. See below for more details.
Error details:
TypeError

    Details: Error running method "message_response": Expected Data or DataFrame or Message or str, got generator



### Reproduction

Make a new project with chat input connected to ollama (enable the streaming toggle) and then the ollama output to chat output. Run the playground. It errors out with the above error when you try to send a chat message. The chat output component will not build, failing with the same error message.

It works fine if you disable streaming.

### Expected behavior

The flow builds and allows the user to chat to the model using the Langflow UI.
