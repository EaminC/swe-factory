default time tool wastes 4400 tokens
### Bug Description

The agent gets a time tool, even if no tools are attached to it.  It makes sense, time is a small simple tool.  But the way it's set up, it provides a giant list of every timezone in the world instead of a simple numerical offset.  That makes the request 4000 tokens before it even gets to anything important.  The timezone tool is useful, but being a default one, it shouldn't provide the enum.
