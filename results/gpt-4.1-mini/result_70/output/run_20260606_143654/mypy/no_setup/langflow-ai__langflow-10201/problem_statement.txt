Ollama integration fails when mirostat is set to "Disabled" in LangFlow
![Image](https://github.com/user-attachments/assets/dfc15f1d-04b9-4eab-b44f-ad9825639325)

### Summary
When using a model in LangFlow with Ollama and `mirostat` set to "Disabled", the integration breaks due to invalid parameters being sent to the Ollama API. The error resolves only after removing `"mirostat": 0` and its related parameters (`mirostat_eta`, `mirostat_tau`) from the model configuration.
---

### Steps to Reproduce

1. Use LangFlow with an Ollama-compatible model like `qwen2.5:0.5b`
2. Set `mirostat` to "Disabled" (default value)
3. Run a prompt or connect to an Agent
4. Error: the Ollama API responds with an invalid option error
