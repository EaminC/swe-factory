[BUG] CrewAI fails to add new memories to Mem0 when in external memory
### Description

CrewAI fails to add memories to mem0 when in an external memory

Failed to add to external memory: API request failed: {"messages":["Expected a list of items but got type \"str\"."],"agent_id":["agent_id is too 
long. Maximum length allowed is 255 characters."]}

### Steps to Reproduce

Add external memory to your crew using 

external_memory = ExternalMemory(
			embedder_config={
				"provider": "mem0", 
				"config": {"user_id": "deck"}
			}
		)

and in the crew 

return Crew(
			agents=self.agents, # Automatically created by the @agent decorator
			tasks=self.tasks, # Automatically created by the @task decorator
			process=Process.sequential,
			verbose=True,
			memory=True,
			external_memory=external_memory,
	)

Run - it fails with 


Failed to add to external memory: API request failed: {"messages":["Expected a list of items but got type \"str\"."],"agent_id":["agent_id is too 
long. Maximum length allowed is 255 characters."]}

every time it tries to add a memory


### Expected behavior

Adding a memory in mem0 

you can see this in https://app.mem0.ai/dashboard/r
