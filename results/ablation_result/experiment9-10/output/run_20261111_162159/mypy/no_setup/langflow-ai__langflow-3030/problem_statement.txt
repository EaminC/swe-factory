Memory Not Passed as Chat History in Tool Calling Agent
### Bug Description

Although the memories are being recorded correctly, they are not being correctly passed as chat history to the agent.

### Reproduction

1. Use the tool calling agent with memory in version 1.0.11 pip.
2. Record some memories using the tool.
3. Attempt to pass the recorded memories as chat history to the agent.
A video demonstrating the issue can be found here: https://jam.dev/c/c7b6d3f6-7151-47a8-89c4-047e04c0aeba

### Expected behavior

The recorded memories should be correctly passed as chat history to the agent.
