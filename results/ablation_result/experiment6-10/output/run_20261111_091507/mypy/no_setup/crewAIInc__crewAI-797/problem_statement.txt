Manager agent in hierarchical process is always verbose when not explicitly set
When running a crew with a hierarchical process and not explicitly setting a `manager_agent`, an agent is assigned with the following:

```python
manager = Agent(
  role=i18n.retrieve("hierarchical_manager_agent", "role"),
  goal=i18n.retrieve("hierarchical_manager_agent", "goal"),
  backstory=i18n.retrieve("hierarchical_manager_agent", "backstory"),
  tools=AgentTools(agents=self.agents).tools(),
  llm=self.manager_llm,
  verbose=True,
)
```

This results in the manager always being verbose, even though the crew is created with `verbose=False`.

Version: 0.30.11
