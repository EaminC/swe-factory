[Feature]: Mem0LongTermMemory adapt to mem0 1.0 version
Currently, Mem0LongTermMemory supports only the open-source version of Mem0 (v0.x). This issue aims to:

- Migrate it to be compatible with mem0 open-source  v1.0, and
- Introduce a new class Mem0CloudLongTermMemory that integrates with the Mem0 Platform — the managed, production-ready SaaS offering.
