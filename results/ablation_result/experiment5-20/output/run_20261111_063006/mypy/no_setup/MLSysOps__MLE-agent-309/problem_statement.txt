[Gemini] Migrate Gemini Integration from Deprecated google-generativeai SDK
The mle-agent's current [Gemini integration](https://github.com/MLSysOps/MLE-agent/blob/6e0dbe25e19ff2f37839984eb028984d198da459/mle/model/gemini.py#L21) is built using the `google-generativeai` Python library, which has been [officially deprecated](https://pypi.org/project/google-generativeai/) by Google and is scheduled for EOL on August 31, 2025.

Need to refactor the GeminiModel class to use the new Google Gen AI SDK [`google-genai`](https://pypi.org/project/google-genai/) instead of the legacy package.
