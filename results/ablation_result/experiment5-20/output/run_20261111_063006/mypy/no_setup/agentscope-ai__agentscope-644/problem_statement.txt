**Describe the solution you'd like**
Enhance AgentScope to support MCP's streamable HTTP transmission. Currently, it only supports stdio/SSE. However, as MCP is progressively phasing out SSE connections in favor of streamable HTTP, it's essential to adapt. Additionally, the official MCP SDK already includes an implementation for a streamable HTTP client.
